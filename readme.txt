Цифровой Марио

Консольный 2D-платформер на стандартном Python

Цель игры
Собрать все монеты (*) и добраться до финишного флага (F), избегая шипов (^) и врага (E). На врага можно прыгнуть сверху, чтобы победить его. У игрока есть 3 жизни.

## Управление
A / D (или стрелки ← / →) — движение влево / вправо
W или Пробел — прыжок
Q — выход
Запуск
Откройте терминал в папке с файлом и выполните:
bash
python index.py
